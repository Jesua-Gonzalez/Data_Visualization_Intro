# Data_Visualization_Intro

This repository is a beginner-friendly guide to data visualization using pandas, matplotlib, and seaborn in Python. Using the Titanic Train dataset from Kaggle (which is downloaded and placed into working folder and not extracted), I demonstrate how to explore and understand data through clear and informative visualizations. You'll learn how to use common plotting functions like sns.countplot(), sns.displot(), and .hist() to uncover patterns and insights in the data. Whether you're new to data science or looking to sharpen your visualization skills, this repo provides practical examples to help you get started.
